AI Chatbot

Developed an AI-powered chatbot using Python, Flask, NLTK, and SQLite. The chatbot processes user queries and provides relevant responses using natural language processing techniques. It includes a simple web interface and stores conversation data for further analysis.

AI Sentiment Analysis

Developed an AI-based sentiment analysis system using Python, Flask, Hugging Face Transformers, and MongoDB. The system analyzes user-provided text and classifies it as Positive, Negative, or Neutral using a pre-trained NLP model. It also stores reviews and displays sentiment results through charts and a web dashboard.
